# Уведомления об обновлениях

При каждом пользовательском обновлении системы обновляйте `release_notes.json`
в том же коммите: задайте новый уникальный `id` и кратко опишите результат для
пользователей. Для небольших исправлений одного обновления можно сохранить
общий идентификатор до выкатки. После выкатки идентификатор не переиспользуйте.

`staff` — описание для сотрудников, `client` — для клиентов, `investor` — для
инвесторов. Не включайте внутренние подробности в клиентское описание.
Закрытие окна хранится на сервере отдельно для каждого пользователя и версии.
Не меняйте идентификатор при обычном перезапуске приложения.
