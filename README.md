# Учёт выполненных работ

Небольшой сайт для учёта работы сотрудников: форма (сотрудник, вид работы,
часы/кол-во, ставка), таблица всех записей, сумма по каждому сотруднику и
общая сумма. Данные хранятся в SQLite (файл `workhours.db`, создаётся
автоматически при первом запуске).

## Запуск локально

Понадобится Python 3.9+.

```bash
cd workhours-app
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Откройте в браузере: **http://127.0.0.1:5000**

## Как выложить в интернет (бесплатные варианты)

Проще всего — **Render.com** (есть бесплатный тариф):

1. Зарегистрируйтесь на [render.com](https://render.com) и подключите свой
   GitHub-аккаунт.
2. Загрузите эту папку в новый репозиторий на GitHub (можно прямо через
   веб-интерфейс GitHub — "Add file → Upload files").
3. В Render: **New → Web Service**, выберите этот репозиторий.
4. Настройки сборки:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app`
5. Нажмите **Create Web Service** — через пару минут сайт будет доступен по
   ссылке вида `https://ваше-приложение.onrender.com`.

Аналогично работает на **Railway.app** и **PythonAnywhere** — общий принцип
тот же: загрузить код, указать команду запуска `gunicorn app:app`.

## Важно про данные

- База данных — это один файл `workhours.db` рядом с `app.py`. На
  бесплатных тарифах некоторых хостингов (например, Render Free) файловая
  система не постоянная и **может очищаться при перезапуске сервиса**. Для
  учебного/личного использования это обычно не критично, но если данные
  должны сохраняться надёжно и долго — на Render стоит подключить платный
  "Persistent Disk", либо перейти на внешнюю БД (например, бесплатный
  PostgreSQL на Render/Railway).
- Резервная копия: можно в любой момент скачать файл `workhours.db` с
  сервера и открыть его любым SQLite-браузером (например, DB Browser for
  SQLite) — там видны все записи в исходном виде.
